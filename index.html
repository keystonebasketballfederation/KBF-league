🔐 KBF OWNER UPDATE CENTER

OWNER USE ONLY — This section explains exactly what to change when you manage the KBF website.

📊 STANDINGS Edit KBF_DATA → standings. Change team name, wins, losses, win percentage and streak.
🏀 PLAYERS Edit KBF_DATA → players. Change player name, team, PPG, RPG and APG.
📅 SCHEDULE Edit KBF_DATA → schedule. Add regular-season games, evening games, playoff games and tournament dates.
🌙 OVERNIGHT TOURNAMENTS Edit KBF_DATA → tournaments. Change tournament name, date, time and status.
🏆 PLAYOFFS The playoff bracket is already built into the website. Update the teams and scores when the playoffs begin.
👑 CHAMPIONS HALL Edit KBF_DATA → champions. Add the champion, runner-up and Finals MVP after each season.
🥇 AWARDS Edit KBF_DATA → awards. Update MVP, DPOY, ROY, Sixth Player, Most Improved, Finals MVP and other honors.
📰 ANNOUNCEMENTS Edit KBF_DATA → updates. These announcements appear at the top of the public website.
